# 模型方法与参数

## 供应风险指数

0–100 分的分析型风险指数由以下维度构成：

- 交期：18%
- OTD：20%
- 质量 PPM：18%
- 产能覆盖：20%
- 单一来源风险：12%
- 地缘风险：12%

这些权重是项目分析假设，不是统计估计得到的真实风险系数。

## 采购策略

### 最低成本
优先调整后到岸成本。

### 均衡
成本指数 55% + 供应风险 45%，在优先分配阶段限制单一供应商集中。

### 韧性优先
成本指数 30% + 供应风险 70%，提高供应分散权重。

## 五类情景

- 需求上升：需求 +20%
- 成本压力：单位成本 +10%
- 供应中断：可用产能 -30%，交期 +25%
- 汇率冲击：非 CNY 供应商到岸成本 +8%
- 基准：不施加额外冲击

## Monte Carlo

600 次模拟同时扰动：

- 需求
- 价格
- 外汇
- 供应商产能
- 低概率较严重的产能中断

输出平均 / P50 / P90 成本、平均物料缺口率、任一物料发生缺口的概率、P90 最大物料缺口率和成本加权供应风险。

## 重要限制

该模型用于展示分析方法，不是经过企业历史数据校准的采购优化引擎。
