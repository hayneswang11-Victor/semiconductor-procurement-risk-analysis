# 项目复现指南

## 环境

建议 Python 3.10+。

```bash
pip install -r requirements.txt
```

## 一键运行

```bash
python src/run_all.py
```

## 分步运行

```bash
python src/00_generate_synthetic_data.py
python src/01_validate_data.py
python src/02_compute_metrics.py
python src/03_run_scenarios.py
python src/04_monte_carlo.py
python src/05_eda_ip_extension.py
```

## 主要结果文件

- `outputs/supplier_metrics.csv`
- `outputs/material_summary.csv`
- `outputs/scenario_strategy_summary.csv`
- `outputs/monte_carlo_strategy_summary.csv`
- `outputs/eda_ip_scenario_summary.csv`

## 复现说明

随机数种子已经固定，因此重新运行时应得到可复核结果。若修改脚本中的参数或随机种子，输出结果会相应变化。
