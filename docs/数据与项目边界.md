# 数据与项目边界

## 可以说明的项目事实

- 使用 Python 建立模拟采购数据与分析流水线；
- 建立采购成本、供应风险、供应商集中度和需求覆盖指标；
- 比较最低成本、均衡、韧性优先三类采购策略；
- 设置需求、价格、产能和汇率情景；
- 使用 Monte Carlo 测试成本与缺口严重度；
- 使用 Excel 建立可编辑采购决策模型；
- 建立 EDA/IP License 需求与授权成本扩展。

## 不应对外宣称

- 有真实供应商谈判经验；
- 使用真实供应商报价或合同；
- 实现了真实采购节省；
- 负责真实 Vendor 生命周期管理；
- 对真实公司进行了采购决策；
- 掌握任何真实 EDA/IP Vendor 的商业报价。

## 数据来源性质

仓库中的业务数据全部为模拟数据，仅用于方法展示和求职项目训练。
