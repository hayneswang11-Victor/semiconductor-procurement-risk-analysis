# Python 脚本说明

- `00_generate_synthetic_data.py`：生成模拟原始数据
- `01_validate_data.py`：检查字段、主键和值域
- `02_compute_metrics.py`：计算供应商成本与风险指标
- `03_run_scenarios.py`：运行五类确定性情景
- `04_monte_carlo.py`：运行 600 次随机压力测试
- `05_eda_ip_extension.py`：运行 EDA/IP 授权采购扩展
- `run_all.py`：按顺序运行全部脚本
- `allocation.py`：采购分配与供应商排序函数
